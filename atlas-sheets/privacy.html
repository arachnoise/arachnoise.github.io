Privacy policy: Atlas Sheets MCP

Home

Atlas Sheets MCP is a private tool for the owner and a few invited collaborators.

  • It asks for access to Google Sheets and Google Drive files only so the owner's AI assistant can read and edit the owner's own spreadsheets.
  • It does not collect, store or sell personal data. It has no server and no database of its own.
  • Data from the spreadsheets is processed by the Claude service (Anthropic) only when the owner asks it to work on a sheet.
  • It does not share data with any other party.
  • Access can be removed at any time at https://myaccount.google.com/permissions.
